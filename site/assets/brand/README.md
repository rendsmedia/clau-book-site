# WM monogram · William Matovu

One mark for the CLAU book and everything on williammatovu.com.

| File | Use |
| --- | --- |
| `wm-mark.svg` | Primary logo: navy disc, gold ring, gold WM and rule. Light backgrounds, print, documents |
| `wm-mark-on-dark.svg` | Same mark without the disc, for navy or dark backgrounds (site header) |
| `wm-monogram.svg` | Letters only, navy. Small spaces, embossing, watermarks |
| `wm-mark-1024.png`, `wm-mark-512.png` | Social profile pictures (YouTube, LinkedIn, WhatsApp), slides |
| `favicon.svg`, `../../favicon.ico`, `apple-touch-icon.png` | Browser tab and phone home-screen icons |

Colours: navy `#282f41`, gold `#f5b21b`, taken from the book cover.
Letters: TeX Gyre Pagella Bold (free licence), converted to outlines, with W and M sharing one stroke.
Keep clear space around the mark of at least the height of the gold rule × 4. Don't stretch, recolour outside navy/gold/white, or add effects.
